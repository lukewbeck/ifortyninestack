# Sources and attribution

Ifortyninestack is original engineering guidance generalized for public use. These public works informed the design.

## Cursor plugins

- [pstack](https://github.com/cursor/plugins/tree/main/pstack), Lauren Tan. MIT License. Routing skill, progressive disclosure, focused review agents, evidence-based verification, and context control.
- [Cursor Team Kit](https://github.com/cursor/plugins/tree/main/cursor-team-kit), Cursor. MIT License. Small operational skills for CI, review, verification, pull request maintenance, and a branch-diff cleanup pass.

## Rails agent methodology

- [Superpowers Rails](https://github.com/fryga-io/superpowers-rails), fryga. MIT License. Built on [Superpowers](https://github.com/obra/superpowers), Jesse Vincent. Vertical-slice planning, intent-level plan steps, and YAGNI during design.

## Writing guidance

- [Google developer documentation style guide](https://developers.google.com/style). Active voice, reader-focused instructions, common-case-first structure, and descriptive links.
- [ASD-STE100 Simplified Technical English](https://www.asd-ste100.org/). Short instructions, consistent terminology, explicit articles, and condition-before-action structure. This plugin treats **negative ontology** as defining work by what it is not. Name the landed change instead.
- William Zinsser, *On Writing Well*. Simplicity, brevity, clarity, and a natural human voice.
- [A Note About Git Commit Messages](https://tbaggery.com/2008/04/19/a-note-about-git-commit-messages.html), Tim Pope.
- [How to Write a Git Commit Message](https://cbea.ms/git-commit/), Chris Beams.

This plugin's conventional commit format takes precedence over the capitalization examples in the two Git articles.

## Plain-language guidance

- [bro-skill](https://github.com/luchasarie/bro-skill), MIT License. Rewrite a prior answer without changing its facts.
- [attention-span](https://github.com/alexgreensh/attention-span), GNU AGPL v3. Answer-first structure and preserving warnings during compression. No source text was copied.

When these sources conflict, current repository instructions and current team process take precedence.
